# Contributing / Правила

## Мова (Language policy)

| Де | Мова |
|---|---|
| Документація (`docs/`, `README.md`, `CONTRIBUTING.md`) | 🇬🇧 English / 🇺🇦 Українська — обидві OK |
| Коментарі в коді | 🇬🇧 English / 🇺🇦 Українська — обидві OK |
| Коміт-меседжі, issue, PR-описи | 🇬🇧 English / 🇺🇦 Українська — обидві OK |
| **Рядки всередині гри (UI, меню, діалоги, назви пісень/тижнів, нотатки, кнопки)** | 🇬🇧 **English ONLY** |

> Причина останнього: мобільні моди і катсцени часто збираються з різних форків, а шрифти
> в HaxeFlixel рендеряться атласами. Кирилиця в базових атласах Psych Engine покривається
> не всюди → «квадратики» замість тексту. Тому будь-що, що гравець бачить **у грі** — англійською.

Локалізація — тільки через механізм `TRANSLATIONS_ALLOWED` (`assets/shared/data/` locale-файли),
а не хардкодом у `source/`.

**Практичне правило:** якщо ти додаєш український текст — він має лежати в `docs/`, `.md`,
коментарях або locale-файлі. Якщо він потрапляє в `assets/` як графіка/рядок у коді гри — це баг.

## Формат експерименту

Один експеримент = одна гілка = один PR = один файл у `docs/experiments/NNN-slug.md`.

Структура файлу: **гіпотеза → навіщо → точка відліку → метод → результат → висновок**.
Шаблон: [`docs/experiments/000-template.md`](docs/experiments/000-template.md).

Правила:
- **Негативний результат публікується.** «Не працює, бо X» — це цінність, а не провал.
- **Ніяких правок без числа.** Якщо це про продуктивність/розмір — потрібен замір до/після.
- Кожна правка має посилання на конкретний файл і рядок (`Project.xml:29`), а не «десь у коді».

## Коміти

Префікси: `exp:` (експеримент), `fix:`, `ci:`, `docs:`, `chore:`.

```
ci: add ABI report to Android build
exp(001): enable hxvlc for armeabi-v7a behind a flag
docs: add language policy
```

## Безпека

- Ніколи не комітити свої ключі/токени. `key.keystore` у репо — **успадкований від upstream**,
  спільний публічний ключ; для реальних релізів він не годиться (див. нижче).
- Для власних збірок: свій keystore + свій `packageName`, ключ — у GitHub Secrets, не в git.
- Зараз `packageName` = `com.shadowmario.psychengine` (`Project.xml:5`) — це означає, що збірка
  конфліктує з іншими Psych-портами при встановленні поруч. Для тестів — ок, для роздачі — ні.
